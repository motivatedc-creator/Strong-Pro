# LOCK’D  
**Brand guidelines & tone of voice · 1.0 · 18 Sep 2026**  
  
Creative direction for the shipped workout tracker currently branded **Certified**.  
This document is the brief for implementation. It is not a brainstorm.  
  
---  
  
## 0. Job of this document  
  
Rename and restyle the product from **Certified** to **Lock’d**.  
  
Keep the product. Change the identity, the voice, and the chrome that still says Certified, aura, “no cap,” or vibes.  
  
Do not invent a new architecture, a new feature set, or a new science layer while doing this.  
  
---  
  
## 1. Name  
  
| Use | Form | Notes |  
|---|---|---|  
| Spoken / prose | **Lock’d** | Apostrophe. Sounds like *locked*. |  
| Wordmark | **LOCKD** | No apostrophe. Condensed extra-bold dies with punctuation. |  
| App name, PWA, `<title>`, manifest | **Lockd** | No apostrophe in system chrome. |  
| Code / bundle / package | `lockd` | Lowercase. |  
| Hashtag / handle | `lockd` | Never `certified`, `repforge`, `strongpro` in new copy. |  
  
**Meaning:** the work is locked in. The file is on this device. History does not get rewritten. A PR is a stamp, not a story.  
  
**Not:** a lock-and-key security brand, a padlock icon company, a “locked-in grindset” meme brand.  
  
**One-line:** The log that stays on this device.  
  
**Tagline:** Keep the receipt.  
  
**Do not use:** “Certified.” “Certified by Lock’d.” “Your aura.” “RepForge” in UI. “That’s Problem behavior.”  
  
---  
  
## 2. Positioning  
  
Lock’d is a serious, local-first strength tracker for people who lift for years.  
  
It logs what happened. It keeps the history honest. It helps the user see whether the training is actually progressing.  
  
It is not:  
  
- a beginner wellness app  
- a social network  
- a coaching marketplace  
- a hype / aura / beast brand  
- an AI chatbot with a logger attached  
  
Certified sounded like a status stamp. Lock’d is a **file stamp**: the session happened, it’s in the record, keep the receipt.

## 3. Mark system  
  
### Wordmark  
- Face: **Barlow Condensed ExtraBold**  
- Set: `LOCKD` (five letters, tracking tight, no outline, no bevel, no gradient)  
- Clear space: one cap-height **L** on all sides  
- Minimum: 120px / 24mm  
- Fallback: Arial Narrow ExtraBold  
  
### Symbol (app icon, favicon, avatar)  
- A stamp **L** — not a padlock, not a C, not a kettlebell  
- Paper field, stamp ink  
- Rounded square, ~6px radius at 32px  
- Minimum: 16px / 8mm  
- At 16px: **L only**. No inner stamp ring, no wordmark, no tagline.
